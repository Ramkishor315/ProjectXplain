# Functional Test Cases

This document records the functional test cases covering user workflows across Features 1 through 10 of **ProjectXplain**.

---

| Test Case ID | Description | Preconditions | Steps | Expected Result | Actual Result | Status |
| :--- | :--- | :--- | :--- | :--- | :--- | :---: |
| **TC-FN-01** | Create project with valid data | Application and database running; user on Create Project view | 1. Enter valid Project Name<br>2. Enter valid Project Idea description<br>3. Click "Create Project" | The project is saved in the database and the user is redirected to the project workspace with the project information displayed. | Not yet executed | **Not yet executed** |
| **TC-FN-02** | Create project with empty fields | Application running; user on Create Project view | 1. Leave Project Name or Idea blank/whitespace<br>2. Click "Create Project" | The form prevents submission and displays an inline validation message requiring both fields, without sending a network request. | Not yet executed | **Not yet executed** |
| **TC-FN-03** | Switch between existing projects | Multiple projects exist in the database; user on Projects list | 1. Navigate to Projects list<br>2. Select a different project card | The workspace switches to the selected project, loading its overview dashboard and updating the active project context in the sidebar and navigation. | Not yet executed | **Not yet executed** |
| **TC-FN-04** | Add functional requirement with priority | User inside active project workspace; on Requirements tab | 1. Click "Add Requirement"<br>2. Enter Title and Description<br>3. Select priority (e.g., High)<br>4. Click "Save Requirement" | The requirement is saved for the selected project and appears in the requirements list with the selected priority. | Not yet executed | **Not yet executed** |
| **TC-FN-05** | Delete functional requirement | At least one requirement exists in the requirements list | 1. Click Delete on the requirement<br>2. Confirm deletion | The requirement is removed from the requirements list and the database, and the project overview count updates accordingly. | Not yet executed | **Not yet executed** |
| **TC-FN-06** | Add user story under requirement | Requirement exists for the project; user on User Stories tab | 1. Click "Add Story" under a specific requirement<br>2. Enter Title and Description<br>3. Submit the form | The user story is saved and appears nested under its parent requirement with its title and description. | Not yet executed | **Not yet executed** |
| **TC-FN-07** | Cascade deletion of user stories | Requirement exists with associated user stories | 1. Delete the parent requirement from the system | The parent requirement and all user stories associated with that requirement are removed from the database and UI without leaving orphaned records. | Not yet executed | **Not yet executed** |
| **TC-FN-08** | Create database entity | User inside active project workspace; on Database Design tab | 1. Click "+ Add Entity / Table"<br>2. Enter Entity Name and Description<br>3. | **TC-FN-10** | Create entity relationship | At least two database entities exist in the project | 1. Click "+ Add Relationship"<br>2. Select From Entity, Relationship Type, and To Entity<br>3. Click "Save Relationship" | The relationship is saved and displayed between the selected entities with the specified relationship type. | Not yet executed | **Not yet executed** |
