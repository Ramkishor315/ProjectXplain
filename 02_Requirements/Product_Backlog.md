# Product Backlog

This backlog documents the prioritized items for **ProjectXplain**, categorized by priority (P0 - Critical, P1 - High, P2 - Medium, P3 - Low) and state (**Completed**, **In Progress**, or **Planned**) relative to the Mid-Semester Evaluation milestone.

---

## 1. Prioritization Scheme

- **P0 (Critical)**: Foundational capabilities essential for core project functionality, data persistence, and baseline viva evaluation.
- **P1 (High)**: Core educational features required to deliver the full 10-feature project design and learning workflow.
- **P2 (Medium)**: Quality-of-life enhancements, export features, and visualization upgrades.
- **P3 (Low)**: Future extensions, multi-user collaboration, and production infrastructure.
